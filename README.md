# Digitus_DA_81001

## Setup

Install the project dependencies and create the local environment from the lockfile:

```powershell
uv sync --locked
```

## Run

```powershell
uv run --locked BarcodeReaderUI.py
```

## Build on Windows

```powershell
.\build.ps1
```

## Licenses

The application uses PySimpleGUI. Its license notice and the third-party license texts are available from the **Lizenzen** button in the settings. The bundled executable includes the license files for its dependencies.
